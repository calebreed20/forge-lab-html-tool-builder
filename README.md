## What Forge Lab Does

Forge Lab is built for turning workflow ideas into usable HTML tools without needing to assemble a bigger application stack. You describe the task in plain English, and it produces a tailored single-file utility that can run offline and stay close to the work it serves.

It works well for individuals and teams that need sovereign, domain-focused tools where branding, compliance fields, and local storage are part of the workflow. The emphasis is on portability, straightforward distribution, and the ability to import and export projects with minimal friction.
